# StyleHub - Fashion & Apparel Website

## About the Project
StyleHub is a fashion and apparel e-commerce website developed
using HTML, CSS and JavaScript. It provides users with a simple
and attractive online shopping experience.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## Features
- Home page with hero section and offers
- Fashion product listing
- Product details
- Shopping cart
- Checkout page
- Login and Signup
- Account/Profile
- About Us
- Contact Us
- Responsive design

## Project Structure
- `index.html` - Home page
- `products.html` - Products
- `product.html` - Product details
- `cart.html` - Shopping cart
- `checkout.html` - Checkout
- `style.css` - Website styling
- `script.js` - JavaScript functionality
- `images/` - Website and product images

## Deployment
The project is deployed using GitHub Pages.

## Conclusion
StyleHub demonstrates the practical use of HTML, CSS and
JavaScript to develop a multi-page fashion and apparel website.
